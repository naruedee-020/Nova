เปิดไฟล์ index.html ในเบราว์เซอร์ หรืออัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages

การเผยแพร่: สร้าง GitHub repository แบบ Public > Upload files (index.html, style.css, script.js, assets/) > Settings > Pages > Deploy from a branch > main /root > Save > รอ URL ที่ GitHub แสดง

URL หน้าแรกจริงต้องได้จาก GitHub หลังเผยแพร่ ไม่สามารถระบุล่วงหน้าได้

หมายเหตุ: เว็บไซต์นี้เป็นตัวอย่าง front-end; ตะกร้าใช้ localStorage และไม่มีการชำระเงินจริง
